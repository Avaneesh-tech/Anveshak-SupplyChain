# ANVESHAK – Blockchain Supply Chain Ecosystem

Anveshak is a unified, enterprise-grade blockchain supply chain ecosystem designed to ensure authenticity from farm to consumer using IoT monitoring, geo-tagging, and immutable blockchain logging.

## Project Structure

```text
ANVESHAK/
├── assets/                 # Shared project assets
│   ├── css/
│   │   └── main.css        # Global design system & dashboard styles
│   └── js/
│       ├── core.js         # Auth, sessions, and blockchain simulation
│       └── batch-data.js   # Centralized batch database
├── dashboards/             # Secure role-based portals
│   ├── admin/              # Global oversight & system management
│   ├── buyer/              # Consumer order tracking & verification
│   └── vendor/             # Manufacturing & logistics operations
├── index.html              # Landing page
├── about.html              # Vision & Mission
├── contact.html            # Get in touch
├── how-it-works.html       # Workflow explanation
├── products.html           # Traceable product catalog
├── traceability.html       # Unified blockchain verification engine
├── login.html              # Multi-role authentication portal
├── signup.html             # Ecosystem registration
└── audit_report.md         # Latest system audit results
```

## Key Features

1.  **Unified Traceability**: A central verification engine using expanded data for Ashwagandha, Tulsi, and Neem products.
2.  **Role-Based Dashboards**: Tailored interfaces for Admins, Vendors, and Buyers with real-time stats and metrics.
3.  **Blockchain Simulation**: Simulated immutable logging, transaction hashing, and wallet connectivity.
4.  **Farmer Registration**: Specialized flow for farmers to input data into the ecosystem without requiring a complex dashboard login.
5.  **Premium UI/UX**: Dark-mode support, glassmorphism effects, and responsive design across all endpoints.
